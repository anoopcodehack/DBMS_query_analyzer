Academic Viva Questions & Architectural Reference

Prepared according to Department of CSE Syllabus (Sahyadri College of Engineering & Management).

1. How is 3NF (Third Normal Form) achieved in your database?

Every relation is in 1NF (atomic attributes) and 2NF (no partial dependency on composite keys, as all tables use surrogate single-column PKs). Transitive dependencies are removed: query_name is not stored in BenchmarkResults; instead, foreign keys link BenchmarkResults → BenchmarkRuns → QueryCatalog.

2. Why does an index speed up queries?

Without an index, MySQL executes a Full Table Scan (type: ALL), examining all 100,000 disk pages sequentially ($O(N)$). A B-Tree index maintains a balanced search tree ($O(\log N)$) where leaf nodes store primary key pointers, allowing MySQL to jump directly to matching rows (type: ref).

3. Where is your Database Trigger implemented?

trg_benchmark_result_audit is an AFTER INSERT trigger on BenchmarkResults. It automatically captures the generated NEW.result_id, execution duration, and timestamp, logging it to BenchmarkAudit without requiring application-side insert calls.

4. Where is your Stored Procedure implemented?

CALL GetBenchmarkHistory(p_query_id) accepts an input parameter and performs an optimized 3-table join between QueryCatalog, BenchmarkRuns, and BenchmarkResults, sorted by recorded timestamp.

5. Why not allow users to enter arbitrary SQL in a text box?

Security and system stability. Allowing arbitrary SQL risks SQL injection attacks, accidental destructive statements (DROP TABLE, DELETE), and server denial of service. The project uses a strictly governed Query Catalog with allow-listed queries.

6. What is the formula for Percentage Improvement?

$$\text{Improvement (\%)} = \frac{T_{\text{before}} - T_{\text{after}}}{T_{\text{before}}} \times 100$$ For example, if baseline time is $80\text{ ms}$ and indexed time is $2\text{ ms}$, the improvement is $\frac{80 - 2}{80} \times 100 = 97.5\%$.
